Everything you need to know about EXUCODER Proxy
Getting Started
What is EXUCODER Proxy?
EXUCODER Proxy is a JWT capture and injection tool for Free Fire. It intercepts authentication tokens and allows you to inject your own JWT.
How do I set up the proxy?
1. Start the proxy from the Dashboard
2. Set your Android proxy to 127.0.0.1:8080
3. Open Free Fire and login normally
4. The proxy will automatically capture JWTs
How To Guides
How to inject my own JWT?
1. Go to the Dashboard
2. Paste your JWT token in the input box
3. Click "Inject JWT"
4. The proxy will now automatically replace captured tokens
How to decode a JWT?
1. Paste any JWT in the input box on Dashboard
2. Click "Decode"
3. You'll see the account details
